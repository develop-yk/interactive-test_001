Gesture UI Lab

Web カメラの映像から 手のランドマーク（21点 × 2手） と 顔の表情（52 ブレンドシェイプ） をブラウザ内でリアルタイム推論し、 カメラスルーの画に重ねた UI を手で直接操作します。
映像はすべて端末内で処理され、サーバーに送信されません。

  • 人差し指カーソル移動
  • ピンチクリック / ドラッグ
  • パーリセット
  • 笑顔「いいね」を送る
  • 首の向き背景のパララックス

クリックするとカメラの利用許可を求めます
